# Общие ресурсы сайта

Карты и флаги не хранятся в приложении. Загружаются те же SVG, которые использует
веб, с настроенного сервера API:

- `/static/circuit/<название этапа>.svg`
- `/flags/<код страны>.svg`

`race-countries.json` — небольшой словарь названий стран и кодов URL из
`front/src/helpers/raceCountry.ts`, не копия графических ресурсов. Обновление:
`python3 ios/scripts/export_country_codes.py`.

Сеть выполняет URLSession с URLCache (8 МБ RAM, до 64 МБ на диске), проверкой
HTTP-статуса и ограничением размера SVG. При сетевом сбое используется доступная
успешная копия. Кеширование и повторная проверка учитывают HTTP-заголовки сайта.
Система может очищать кеш; при первом запуске без сети графика недоступна.

SVG отображается в инертной WKWebView-поверхности изображения. Это не веб-экран:
нет JavaScript, навигации, интерактивности или внешних подресурсов; изображение
передаётся как data URL с ограничивающей CSP. Для карты извлекается основной
подконтур из исходного SVG; оформление соответствует теме приложения.
Интерфейс, навигация, расписание и данные остаются в SwiftUI.

Происхождение исходных ресурсов и ограничения — в корневом ASSET_LICENSES.md.
В проекте остаётся собственный векторный знак поддержки, используемый как UI-иконка.
