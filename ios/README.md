# TurboTears iOS

SwiftUI, Swift 6, iOS 26+. Внешних пакетных зависимостей нет.
Открывать `TurboTears.xcodeproj`, схема **TurboTears**, затем Run (⌘R).
`Package.swift` нужен для тестов Core, это не запускаемое приложение.

## Сервер и ресурсы

По умолчанию приложение подключено к **https://new.f1hub.ru**:
рабочий `/api/v1/weekend`, зачёты, классификации и статистика трасс.
При первом запуске этой версии старый адрес заменяется рабочим сервером.
После этого его можно изменить через «Меню → Сервер API».
Для разработки в симуляторе допустим `http://localhost:8000`.
На настоящем iPhone localhost относится к телефону — нужен HTTPS-адрес сервера.

Карты и флаги загружаются с сайта по тем же SVG-URL, что в вебе, и кешируются.
Скопированные в iOS картинки и экспортированные контуры удалены. Подробнее:
`TurboTears/Resources/README.md`. При первом запуске без интернета графика недоступна.
Сервер развёртывать для текущих маршрутов не потребовалось: публичные API и
SVG-ресурсы проверены и возвращают HTTP 200.

## Текущие функции

- Главная: гонка с флагом и схемой, старт/отсчёт, раскрываемое расписание,
  зачёт пилотов/команд, быстрые ссылки и четыре раздела.
- Уик-энд: выбор сезона/этапа, результаты сессий и профиль трассы.
- Цвета двух тем из веба, сохраняемый выбор темы.
- Кеш расписания по серверу/сезону/этапу; повторы и сохранённая копия при сбое.
- Проверка season/round/session: другой этап или практика не выдаются за выбранные.
- Игры, прогнозы, справка, архив и правовые страницы пока открываются на сайте.

Избранное, вход, персональная карусель, уведомления, виджеты и Live Activities
ещё не перенесены. Подключение рабочего сервера не означает авторизацию аккаунта.

## Стеклянные переключатели

Общий `App/Components/LiquidGlassSwitch.swift` использует одну материальную
подложку и настоящую интерактивную Liquid Glass-линзу с `glassEffectID` и
`glassEffectTransition(.matchedGeometry)`. Обычная цветная заливка индикатора
удалена. Это публичные SwiftUI API; точная внутренняя физика UITabBar не является
доступным отдельным компонентом Apple, полная идентичность ей не гарантируется.

Работают нажатие и горизонтальный жест с выбором после отпускания.
GestureState сбрасывает отменённый жест; вертикальное движение не меняет выбор.
Сохраняются подписи и selected для VoiceOver, цели от 44 pt, RTL и крупный текст.
Reduce Motion отключает добавленную анимацию; Reduce Transparency/Increase Contrast
дают непрозрачный вариант. Полный ручной аудит жестов и VoiceOver ещё не выполнен.

## Проверки

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project TurboTears.xcodeproj -scheme TurboTears -configuration Debug \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath DerivedData CODE_SIGNING_ALLOWED=NO build
```

Сборка проверена в Xcode 27.2. Core: 10 тестов, изолированные сетевые ответы.
Подключение публичного сервера отдельно проверено в симуляторе, снимок —
`Preview/screenshots/home-live-server.png`. Этот снимок содержит реальные
публичные данные на момент проверки, а не фиксированный эталон расписания.

Для изолированной проверки отдельно запускается `python3 Preview/server.py`.
Он слушает 127.0.0.1:18765 и не обращается к рабочей БД. Адрес для превью нужно
задать явно; production по умолчанию не использует fixtures.

Для App Store ещё нужны иконка, подпись, нативные юридические экраны,
локализация и проверки на устройстве. Отдельный удалённый репозиторий не создан;
папку ios можно перенести самостоятельно.
