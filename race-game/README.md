# Emerald Loop

Самостоятельный прототип пиксельной браузерной гонки на Phaser и TypeScript.

## Локальный запуск

```bash
npm install
npm run dev
```

Vite покажет локальный адрес игры. Для проверки с телефона откройте сетевой адрес компьютера, который Vite напечатает рядом с `Network`.

## Управление

- `W`, `↑` или `пробел` — газ;
- `S` или `↓` — тормоз и задний ход;
- `A/D` или `←/→` — поворот;
- `R` — вернуть болид на ближайшую точку трассы;
- `P` — пауза;
- на сенсорных устройствах появляются четыре экранные кнопки.

## Ассеты

- `public/assets/open-wheel-car.png` — оригинальный вымышленный болид с открытыми колёсами;
- `public/assets/emerald-loop-track.png` — оригинальная трасса Emerald Loop с окружением.

Оба изображения созданы специально для проекта встроенным ImageGen. Они не используют реальные логотипы, спонсорские знаки, названия команд или существующие схемы трасс.
