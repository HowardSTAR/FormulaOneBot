# Emerald Loop

Пиксельная браузерная гонка на Phaser и TypeScript: Emerald Loop, Sunset Speedway (овал), Canyon Switchback (техничная), Harbor Sprint (городская). На каждой трассе — три круга, отдельный рейтинг, личный прогресс и призрак рекорда.

Трасса выбирается перед стартом или через «Меню → Выбрать трассу» (текущий заезд сбрасывается). Выбор сохраняется в браузере. Схемы, препятствия и контрольные точки определены в `app/race_tracks.json`; этот файл используется и игрой, и серверной проверкой.

Столкновения работают с деревьями, зданиями, скалами, шинами и ограждениями. Асфальт, поребрики и трава проезжаемы; трава замедляет. Призрак не является препятствием. Болид имеет капсульную форму столкновения, удар снижает скорость, вдоль стены можно скользить, от неё можно отъехать задним ходом.

Обновлённая Emerald использует `emerald-loop-v2`. Старые рекорды `emerald-loop-v1` остаются в БД и доступны кнопкой «Архив Emerald · до столкновений», но не участвуют в новом рейтинге и не используются как призрак.

Возврат на трассу (`R` / ↺) переводит начатый заезд в тренировку: он не записывается ни в локальный рекорд, ни в общую таблицу. Для новых трасс сервер проверяет начало на старте, последовательность контрольных точек, три пересечения финиша, непрерывность записи и разумную скорость перемещения. Это базовая проверка записи, не полноценная защита от подделки клиента.

## Локальный запуск

```bash
npm install
npm run dev
```

Vite покажет локальный адрес игры. Для проверки с телефона откройте сетевой адрес компьютера, который Vite напечатает рядом с `Network`.

Команда `npm run build` создаёт автономную сборку в `dist`. Для встраивания в основной React-сайт содержимое `dist` копируется в `front/public/race-game`, после чего маршрут `/race-game` открывает игру в полноэкранном контейнере.

## Управление

- `W`, `↑` или `пробел` — газ;
- `S` или `↓` — тормоз и задний ход;
- `A/D` или `←/→` — поворот;
- `R` — вернуть болид на ближайшую точку трассы;
- `P` — пауза;
- на сенсорных устройствах доступны джойстик руля, газ и тормоз.

В игровом меню доступны возврат на главную страницу и общая таблица лидеров. Результат трёх кругов отправляется в API только для авторизованного пользователя, включившего участие в общем игровом рейтинге.
