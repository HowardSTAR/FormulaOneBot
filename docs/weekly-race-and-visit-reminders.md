# Уведомления о недельных рекордах и напоминания при входе

При сохранении проверенного заезда на трассе текущей недели создаётся событие
для участников, которых игрок действительно обогнал. Ничья, собственный
результат, улучшение уже опережающего времени и другая трасса событий не создают.
Событие, заезд и одна актуальная запись во входящих сохраняются одной транзакцией.

Очередь обрабатывается каждые 30 секунд. Частые события для одного участника
объединяются; в Telegram отправляется не больше одного такого уведомления в час.
Сообщение содержит имя, время и кнопку повторного заезда. Учитываются существующие
настройки звука и тихие часы. Повтор после перезапуска не создаёт дубль.
Перед отправкой проверяются актуальность рекорда, участие в рейтинге и конец недели.

На сайте показывается один компактный блок над содержимым страницы. В порядке приоритета:
обогнанное время, ближайшая сессия, срочный несохранённый прогноз, новый доступный
прогноз и новая недельная трасса. Уже сохранённый или закрытый прогноз не предлагается;
новая неделя показывается только первые двое суток и до первого недельного заезда.
Сессии учитываются в пределах ближайших суток; отменённый этап не предлагается.

Кнопка действия и крестик закрывают строку на текущую сессию браузера.
Закрытое событие подавляется на сутки или до своего окончания, если оно раньше.
Подавление отделено для каждого аккаунта; при недоступном хранилище остаётся
закрытие в памяти. В играх, административных разделах и формах аккаунта строка скрыта.
Таймеры приостанавливаются в фоновой вкладке. Неудача персонального API не выдаётся
за отсутствие заезда. При смене аккаунта старый ответ отбрасывается.

## Проверка

```powershell
.venv-codex/Scripts/python.exe -m pytest tests/test_weekly_overtakes.py tests/test_engagement.py tests/test_weekly_race_notifications.py -q
```

Из `front`: `npm run test:performance`, `npm run lint`, `npx tsc -b`,
`npm run build:front` и `npm run check:budget`.

Для браузерной проверки запустить `tests/ux_preview_server.py` и Vite на порту 5174
с `F1HUB_PREVIEW_API=http://127.0.0.1:8009`, затем из корня:
`node scripts/check-visit-reminders-ui.cjs`. Скрипту нужен Playwright и Edge;
проверяются ширины 320, 390 и 1440 px. Все отправки перехвачены, сообщения
и реальные прогнозы не создаются.
