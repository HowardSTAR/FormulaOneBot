# Профили участников

Свой профиль открывается по `/profile` из меню «Мой профиль» и аккаунта.
Профиль другого участника — `/profile/<users.id>`, включая ссылки в таблице прогнозов.
Оба варианта поддерживают сессию сайта и авторизацию Telegram Mini App.

В шапке показан лучший начисленный прогноз выбранного сезона по числу баллов.
При равенстве выбран более ранний этап. По умолчанию используется текущий год UTC.
Ниже доступны ответы прогнозов, сумма баллов и лучшие времена по каждой трассе.
Владелец видит свои неначисленные прогнозы; остальные — только начисленные.
Игровые рекорды других участников отображаются только при включённом участии
в игровых таблицах. Email, Telegram ID и телеметрия в профиль не передаются.

## Подписки

- «На старт»: значок в профиле и таблице прогнозов, общая лига сторонников.
- «Свой стиль»: предыдущие преимущества, красная/серебряная рамка,
  красный/синий ник, фоны «Стартовая решётка» и «Алый».
- «Полный газ»: предыдущие преимущества, золотая/неоновая рамка,
  золотой/мятный ник, фоны «Сияние» и «Чемпион».

Права вычисляются сервером из подтверждённого состояния Boosty.
Существующий `BOOSTY_PILOT_TELEGRAM_IDS` продолжает ограничивать автоматическую
проверку подписок. Ручное включение премиума даёт все варианты, ручное выключение
отключает преимущества подписки. Неизвестный оплаченный уровень даёт только
значок и лигу. При понижении уровня недоступные варианты заменяются базовыми
при отображении; сохранённый выбор восстанавливается после возвращения уровня.

Лига сторонников формируется из действующих сторонников с профилем прогнозов,
использует существующие сезонные результаты и порядок общего зачёта.
Отдельного вступления не требуется, прогнозы повторно не отправляются.

Оформление сохраняется в `user_profile_styles`, миграция выполняется при
инициализации базы. При объединении аккаунтов оформление целевого аккаунта
имеет приоритет; если его нет, переносится оформление исходного.

## Проверки

`tests/test_user_profiles.py` проверяет доступ, понижение уровня, скрытие ответов,
выбор лучшего прогноза, рекорды, лигу и перенос оформления.
`scripts/check-user-profile.cjs` проверяет интерфейс на 320, 390, 768 и 1440 px
с локальными тестовыми ответами API. Для него нужны Playwright, Edge
и сервер Vite по адресу `http://127.0.0.1:5174`.
