# Ручной премиум главного администратора

В админке `/admin?section=users` главный администратор видит блок «Мой премиум»:

- «Включить премиум» включает статус независимо от подписки и настройки Boosty.
- «Отключить премиум» выключает статус даже при активной подписке.
- «По подписке Boosty» отменяет ручной выбор и возвращает автоматический режим.

Доступ проверяется на сервере: нужна административная сессия и совпадение
с главным аккаунтом из `ADMIN_EMAIL` или `ADMIN_TELEGRAM_ID`. Другие
администраторы и superadmin управлять этим статусом не могут. Запросы работают
только с аккаунтом текущей сессии, без передачи ID целевого пользователя.
При входе через cookie изменение защищено существующей проверкой CSRF.

Ручной выбор хранится в отдельной таблице `premium_overrides`, создаваемой
при инициализации БД. Синхронизация Boosty её не меняет. Роль аккаунта и
подтверждённый статус подписки Boosty сохраняются отдельно. Изменения режима
попадают в журнал админки; запись премиума и аудит сохраняются одной транзакцией.

`GET/PATCH /api/admin/me/premium` возвращают актуальный статус. Тело PATCH:
`{"mode":"enabled"}`, `{"mode":"disabled"}` или `{"mode":"boosty"}`.
Ответ `/api/account/boosty` дополнен `premium_active` (итоговый статус) и
`premium_override` (`true`, `false` или `null` для автоматического режима).
Поле `active` по-прежнему обозначает только подтверждённую подписку Boosty.
Значок в личном кабинете использует итоговый статус, у ручного включения своя подпись.

Этот статус пока управляет значком в кабинете. Ограничений платных функций
в текущей версии приложения нет. Для применения нужны новый backend и frontend;
перенос данных вручную не требуется.
