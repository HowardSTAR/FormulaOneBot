# Страница прогнозов TurboTears

Режим Impeccable: Operate. Страница `/predictions` помогает выбрать исходы этапа и сохранить прогноз до первой квалификации. Главное действие — отправка или обновление прогноза; личный сезон, общий зачёт и приватные лиги остаются отдельными разделами того же маршрута.

## Принятые решения

Оформление продолжает обновлённую главную, без замены визуального языка. Общая панель `HomeToolbar` содержит тему, уведомления и профиль. Нижний `HomeDock` сохраняет общую навигацию; локальные разделы используют `GlassSwitch` с настоящими ссылками и текущим разделом в URL. Ссылки сохраняют остальные параметры и приглашение в hash. Четыре раздела показываются только иконками с aria-label и title; меню остаётся в одну строку, включая крупный текст. Ссылки и горизонтальный drag используют штатный GlassSwitch.

Порядок на телефоне: заголовок → срок приёма → разделы → этап/участник → выборы → отправка → необязательная привязка Telegram → правила. На широком экране заголовок соседствует с тем же декоративным подиумом, который используется на главной; финишная пятёрка располагается слева, а другие события и SC — справа. Спринтовая группа, если она есть, идёт первой. На телефоне группы следуют друг за другом. На телефоне подиум уменьшается или скрывается, чтобы не отодвигать форму. Маркеры P, 1–5, FL и DNF несут значение категории. Убраны дублирующий F1 Forecast, номер шага, отдельные рамки вокруг каждого поля и глобальное правило `button:disabled` из старого CSS.

Шрифт наследуется от общего каркаса. Space Grotesk сохранён для подиума, маркеров и числовых мест — это существующее решение TurboTears, поэтому предупреждение Impeccable об этом шрифте принято осознанно. Размеры текста формы, истории, условий титула и разбора поддерживают увеличение корневого шрифта.

### Токены и контраст

Используются существующие `--design-*`, новые палитры не вводятся. Контраст рассчитан по sRGB для непрозрачных поверхностей; это проверка выбранных пар, а не заявление о полном соответствии WCAG.

| Фон | `#f5f5f7` / `#141518` | — |
| Surface | `#ffffff` / `#202125` | — |
| Основной текст | `#202126` / `#f2f2f4` | 16.07 / 14.39 |
| Вторичный текст | `#64666e` / `#b0b1ba` | 5.73 / 7.54 |

Основная кнопка использует `--design-event-bg` и `--design-event-ink`: белый на `#b92b25`, 6.11:1. Стекло сохранено для навигации и инструментов. Остальной контент спокоен и непрозрачен. В разборе точность обозначается цветом, значком и текстом; карточки, фильтры и статусы следуют теме.

## Доступ и поведение

Серверный контракт, CSRF, сроки и права не менялись. `signedIn`, привязка Telegram и подписка остаются разными признаками. Гость видит публичную форму и может сохранить черновик перед входом в прежнем потоке; личные разделы требуют аккаунта. Привязка Telegram остаётся необязательной для прогнозов.

Кнопкам машины безопасности добавлен `aria-pressed`, полю имени — доступное название и autocomplete, ошибке — alert, загрузке и успеху — status. Ошибка начальной загрузки предлагает повтор. Отдельное состояние отсутствующего этапа не показывает незаполняемую форму. Таблицы имеют собственные доступные горизонтальные области прокрутки. Для пилотов сохраняется существующий picker с поиском, запретом повторов в пятёрке, Escape и возвратом фокуса; необязательный `imageUrl` поддерживает локальные фото в fixture, production по-прежнему использует API портрета, если URL не предоставлен.

Основания решений: `apple-design/references/hig/layout.md` (адаптация к доступному месту), `entering-data.md` (понятный ввод и выбор), `segmented-controls.md` (ясное выбранное состояние); `web-design-guidelines` (семантика ссылок, имена контролов, фокус, темы); `frontend-design` (подходящая предмету графика); Impeccable craft-floor/polish (иерархия, спокойные поверхности, проверка в браузере).

## Локальная проверка

Демо: `/tests/home-design-preview.html?page=predictions&auth=member&theme=light`. Это Vite-only fixture с явно вымышленными данными, без записи в backend. `auth=guest|member|linked`, `tab=form|leaderboard|history|leagues`, `format=sprint`, `championship=1`, `scale=2`. Состояния: `prediction-error`, `prediction-loading`, `prediction-before`, `prediction-closed`, `prediction-finished`, `prediction-name`, `prediction-empty`, `prediction-saved`, `prediction-save-error`. Ошибка загрузки учитывает предварительный запрос общего напоминания.

Запущены:

- `npx tsc -b`, `npm run lint`, `npm run build:front` — успешно. Vite сохраняет предупреждение о крупном общем chunk race-game.
- `npm test` — 206 тестов, все прошли.
- `scripts/check-predictions-design.cjs`: обе темы на 320, 390, 768, 899, 900, 1024, 1440 и 1920 px; четыре раздела, выбор/поиск пилота, запрет повторов, SC, открытые/закрытые сроки, загрузка, retry, гость, имя, пустая таблица, ошибка/успех сохранения, спринт и условия титула. 200% текст на 320, 390, 900, 1440 px; клавиатурный фокус и отсутствие переполнения. Дополнительно проверены drag переключателя, сохранение season/hash приглашения, отсутствие подчёркивания при hover, reduced motion и повышенный контраст.
- Существующий `scripts/check-prediction-review-ui.cjs` с `BROWSER_CHANNEL=chrome`: 320, 390, 768, 1440 px; разбор, фильтры, sharing success/error, retry, Escape, восстановление фокуса и пустой сезон.
- Scoped Impeccable detect: замечания только о выбранном брендовом Space Grotesk. Результат дополнен ручным просмотром светлых и тёмных desktop/mobile снимков и 200% текста.

Скриншоты по умолчанию сохраняются в `/tmp/turbotears-predictions`. Для браузерных сценариев нужен локальный Vite, Playwright и установленный Chrome; адрес регулируется переменными окружения скриптов.

Не проверены реальные production API и авторизация внешнего сервера, отправка в Telegram, screen reader и другие браузерные движки. Коммиты, push и публикация не выполнялись.

## Итерация: выбор в виде состава на гонку

По запросу пользователя длинные поля с повторяющимся «Выберите пилота» заменены цельными слотами. Пустой слот показывает позицию/категорию и плюс, выбранный — портрет по пояс, имя, команду и стрелку изменения. Цифры 1–5 представляют реальные позиции; P, FL, DNF и спринтовые маркеры обозначают категории. Подсветка выбранного слота использует существующий цвет команды с низкой интенсивностью; текст не маскируется. Фото сохраняют пропорции, низ и края портрета плавно растворяются. Слоты имеют минимум 82 px высоты, SC — кнопки по 44 px.

Реализация: `DriverPicker` получил необязательный `variant="slot"`; обычный вариант для других страниц сохранён. Поиск, блокировка повторов внутри пятёрки, доступное имя, Escape, возврат фокуса, хранение ответов и серверные сроки используют прежние механизмы. CSS новых слотов отделён в `prediction-slots.css`, прежние перекрывающие правила отдельных полей удалены.

После этой итерации повторены TypeScript, lint, production-сборка и браузерный сценарий `check-predictions-design.cjs`: обе темы, пустые и заполненные слоты, 320–1920 px, спринт, 200% текст, поиск и повторный выбор, запрет дублей, ошибка/успех сохранения. Дополнительно просмотрены изображения заполненной формы на телефоне и десктопе. Scoped Impeccable detector сообщает только о сохранённом брендовом Space Grotesk. Production API в этой визуальной итерации не вызывался.

## Итерация: фон шапки и иконки разделов

По явному запросу пользователя локальное меню прогнозов показывает только четыре иконки во всех размерах. Настоящие ссылки, aria-label, title, выбранное состояние и клавиатурный доступ сохранены. Двухрядное текстовое состояние удалено; одно меню остаётся в одну строку.

Подиум увеличен с 350×190 до 470×230 px (в пределах доступной ширины). Боковые ступени ярче, затухание снизу начинается позже. Добавлен рассеянный фон с маской по четырём краям. На телефоне тот же подиум работает как декоративный фон справа, с opacity .22; текст и фокус не маскируются. Вторичный текст шапки усилен для контраста поверх подсветки. При повышенном контрасте декор скрывается.

Проверены обе темы на 320, 390, 900, 1440 и 2560 px, увеличенный текст 200%, размеры целей и переходы иконок. TypeScript, lint и build проходят; механический detector оставил только замечания о сохранённом брендовом шрифте. Логика прогнозов в этой итерации не менялась; production API не проверялся.

## Личный разбор: компактные сравнения и оболочка окна

Разбор теперь содержит компактную сводку, цветные фильтры статусов и сетку категорий в две колонки на широком экране. Каждый ответ сравнивается с фактическим результатом через сезонный `DriverPortrait`, имя и командную подсветку. Фотографии по пояс мягко растворяются внизу и по краям. Если метаданные не загрузились, код ответа остаётся читаемым; команды не угадываются. Несколько пилотов в первой группе схода показываются по отдельности. SC и неизвестные значения сохраняют текстовое представление.

Угаданные ответы выделены зелёным, частичные — золотистым, ошибки — красным, ожидание фактов — синим. Цвет дополнен текстом и SVG-символом. Подробная причина, позиция и правила раскрываются через прежнее «Как считаются очки». На телефоне фильтры прокручиваются в одну строку. При крупном тексте сводка и сравнения переходят к вертикальному порядку. Убраны порядковые декоративные номера, вложенные рамки вокруг значений и прежние крупные отступы.

Оболочка: широкое нативное модальное окно с акцентной шапкой и круглым закрытием на десктопе; на телефоне — панель снизу с закреплённой шапкой, отдельной прокруткой и safe areas сайта/устройства. Вход 320 мс для панели и 220 мс для окна, выход 180 мс. Движение отключено при reduced motion; прерывание входа закрытием начинается с текущего положения. Escape, нажатие за пределами окна, блокировка фоновой прокрутки и возврат фокуса сохранены. Close остаётся доступным при прокрутке.

Серверные данные, расчёт баллов, доступ и подтверждение фактов не менялись. Локальный fixture исправлен: разные статусы теперь согласуются с общей суммой 25 из 37; прежние вымышленные 22 балла при девяти точных попаданиях были несогласованными.

Проверки: TypeScript/lint/build; существующий `check-prediction-review-ui.cjs` (фильтры, loading/error/retry, неизвестные/ожидаемые факты, sharing, Escape и фокус на 320/390/768/1440 px); новый `check-personal-review-design.cjs` (обе темы на 320/390/768/1440/1920 px, сезонные портреты, групповой первый сход, фильтры, раскрытие деталей, scroll lock, close/backdrop, анимация и 200% текст на 320/390/1440 px). Scoped Impeccable scan для разбора не дал замечаний. Снимки сохранены в `artifacts/personal-review-design-*.png`. Проверки API и отправки выполнены только с локальными ответами; production и другие браузерные движки не проверены.
