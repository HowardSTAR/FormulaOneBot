# Выбор напоминаний о сессиях

В боте: «Настройки» → «Выбрать сессии для напоминаний». Каждое нажатие сохраняется сразу.
На сайте: «Настройки» → «О каких сессиях напоминать» → «Сохранить настройки».

Пять категорий: свободные заезды (вместе FP1–FP3), квалификация, гонка,
спринт-квалификация и спринт. По умолчанию все выбраны, включая существующие
аккаунты. Можно отключить все категории. Общий переключатель уведомлений бота
не включается автоматически; разрешение браузерного push выдаётся отдельно.
Для синхронизации с ботом сайт должен использовать связанную учётную запись.
Аккаунты сайта без Telegram тоже могут менять свои напоминания.

Выбор влияет только на напоминания до старта, а не на результаты, голосования
и прогнозы. Групповые рассылки остаются без изменений. История браузерных
уведомлений сохраняется; ещё не отправленные push отключённой категории
отбрасываются. Прошедшие сессии не рассылаются задним числом.

Хранение: users.reminder_sessions, маска 0–31: FP=1, qualifying=2,
race=4, sprint qualifying=8, sprint=16. Миграция при обычном запуске приложения
добавляет столбец без сброса существующих настроек. API /api/account/settings
работает по ID аккаунта с авторизацией сайта/Telegram; старый /api/settings
сохранён. Отсутствующее поле в запросе не меняет ранее сохранённый выбор.

## Несколько интервалов

В боте: «Настройки» → «Напоминать за» → отметьте несколько кнопок → «Готово».
Отметки сохраняются сразу. На сайте и в Mini App выберите интервалы флажками
«Уведомлять заранее» и нажмите «Сохранить настройки». Доступны 15, 30, 60,
120 и 1440 минут. Каждому выбранному моменту соответствует отдельное напоминание;
повторный проход планировщика или перезапуск не создаёт дубликат.

Пустой список отключает только напоминания о старте. Результаты, голосования,
сообщения о прогнозах и групповые рассылки не меняются. Ещё не отправленные
напоминания снятого интервала отменяются при доставке. Уже отправленные сообщения
продолжают обновлять свой статус. Напоминание за 120 минут перед закрывающей
прогнозы квалификацией в личном чате заменяется существующим сообщением о прогнозах.
Остальные выбранные интервалы работают независимо. Пропущенные интервалы не
рассылаются задним числом; браузерный push включается отдельно.

Хранение: nullable `users.notify_before_mask`, биты 15=1, 30=2, 60=4, 120=8,
1440=16. NULL сохраняет прежний `notify_before`, 0 означает явное отключение.
API возвращает `notify_before_minutes` — нормализованный список минут.
Старые клиенты без этого поля не сбрасывают сохранённый множественный выбор.

## Статус уже доставленного напоминания

Бот проверяет статус каждые 30 секунд и через общую очередь редактирует исходное
сообщение, без новой рассылки:

- До старта остаётся обратный отсчёт.
- После начала: «УЖЕ ИДЁТ» без относительного времени «… минут назад».
- После гонки: «Этап прошёл». После FP, квалификации и спринта: «Сессия прошла»,
  чтобы не объявлять весь гоночный уик-энд завершённым после одной тренировки.

Явные статусы завершения и время конца сессии имеют приоритет. Текущее расписание
FastF1 отдаёт время старта, но не фактического финиша, поэтому запасная оценка
помечается «Статус по расписанию»: FP — 60 минут, квалификация — 90 минут,
спринт-квалификация и спринт — 60 минут, гонка — 180 минут. Это не подтверждение
фактического финиша при задержках или красных флагах. Если источник явно сообщает
продолжающуюся/приостановленную сессию, оценка времени не объявляет её завершённой.

Обновление не мгновенное: к интервалу проверки добавляется очередь доставки
(обычно до следующего 30-секундного прохода, при лимитах Telegram — дольше).
Задание `reminder_status` запускается только после инициализации БД.

Используются сохранённые ID доставленных сообщений из `telegram_deliveries`,
включая старые напоминания за последние три дня. Без подтверждённого ID сообщение
не редактируется. Архивированные аккаунты пропускаются; удалённые сообщения
не заменяются новыми. Правки дедуплицируются, переживают перезапуск и повторяются
при временной ошибке сети. Старое обновление «идёт» не перекрывает завершение.
Рабочие сообщения и БД при локальных тестах не изменяются.

Метод редактирования: [Telegram Bot API · editMessageText](https://core.telegram.org/bots/api#editmessagetext).
