# Трофеи профиля

Коллекция использует 24 изображения пользователя: восемь семейств × бронза, серебро, золото. Прозрачные WebP 384px подготовлены командой `python scripts/prepare-trophy-assets.py <каталог PNG>`; оригиналы не меняются.

Сервер начисляет награды при проверке `/api/profiles/me/trophies` по сохранённым результатам. Оракул: 1/5/15 верных победителей основной гонки; подиум: 1/3/7 точных троек. Участие: 3 этапа / половина с округлением вверх / весь текущий сезон. Источник цели — действующий календарь; отменённые этапы исключаются из цели и прогресса. При недоступном календаре цель не угадывается. Золото ожидает результатов всех действующих гонок и окончания финальной гонки (не ранее шести часов от её старта). Полученные сезонные награды сохраняются с годом, новый сезон начинает свой счётчик.

Реакция: по три сохранённых старта ≤350/280/220мс. Гонка: 3/10/25 подтверждённых полных заездов со временем ≤105% предыдущего личного рекорда на той же версии трассы; первый заезд задаёт базу. Повторять результат разрешено. Архивные заезды без проверенной телеметрии не учитываются. Исследование: результат в 1/2/3 разных играх. Reflex Grid: 10/15/20 попаданий за одну попытку в режиме `timed`, сложности `medium`, длительностью ровно 10000мс.

Поддержка: 30/90/365 дней объединённых оплаченных интервалов Boosty. Подтверждённые интервалы записываются при полной успешной синхронизации, от момента проверки до `nextPayTime`. Пересечения объединяются. Дни до начала учёта не восстанавливаются по текущему статусу; ручной premium override не подтверждает оплату. Разрыв не обнуляет счётчик.

Награды в `user_trophies` выдаются идемпотентно и не отзываются при пересчёте календаря. `seen_at` — подтверждённый просмотр окна получения, а не признак владения наградой. После входа, принятого игрового результата и возвращения на вкладку клиент проверяет очередь. Для Emerald Loop сообщение проверяется по origin и iframe source. Клиентские события запускают только серверную проверку и не могут выдать награду. Анимация не прерывает другой открытый диалог или онбординг.

Новые награды показываются по очереди: медаль, световой акцент, частицы, кнопки получения и просмотра коллекции. Автозакрытия нет. Сохранение просмотра — `POST /api/profiles/me/trophies/seen`; при ошибке доступен повтор. Повторная отправка безопасна. `prefers-reduced-motion` убирает движение и вспышки.

Бейдж выбирается только из выданных уровней, включая ранние и прошлые сезоны: `PATCH /api/profiles/me/trophy-badge`. Сервер проверяет владельца. Публичный `/api/profiles/{id}/trophies` отдаёт только выданные награды и бейдж, без скрытого прогресса и очереди. Связывание аккаунтов переносит награды, просмотренные уведомления, бейдж и подтверждённые периоды поддержки.

Проверки: `pytest tests/test_trophies.py`, `npm --prefix front test`, TypeScript, сборка, бюджет начальной загрузки. `node scripts/check-trophies.cjs` проверяет браузером очередь, сетевую ошибку и повтор, Escape, пакетное подтверждение, отсутствие повтора после перезагрузки, бейдж и публичный профиль на 320/390/768/1440px.
