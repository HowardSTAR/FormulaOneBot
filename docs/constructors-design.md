# Команды TurboTears

Раздел `/constructors` продолжает главную и соседний зачёт пилотов: существующие
`--design-*` токены двух тем, Space Grotesk для чисел, мягкая командная подсветка.
Назначение страницы — просмотреть весь зачёт выбранного сезона и открыть команду.
Это расширение принятого интерфейса, без новой дизайн-системы и изменений прав.

Одна адаптивная разметка: заголовок, сезон и история; лидер с болидом; полный
упорядоченный список команд. На широком экране лидер соседствует с заголовком,
на телефоне следует за ним. В строках выровнены место, команда, отставание и очки;
в узком контейнере очки и отставание собраны в один блок справа. Подпись
не создаёт дополнительную строку сетки: обычная мобильная строка занимает 72 px.
При тексте 200% на самом узком экране допускается перенос ради читаемости. Вся строка — ссылка
с `constructorId` и выбранным `season`. Ноль очков сохраняется. Избранное
отмечается по ответу API. Для исторических сезонов первый участник подписан
«Лидер зачёта», без предположения об окончательности чемпионата.

Ссылка на историю подписана «Сравнить команды по сезонам», со значком графика.
Кнопка и выбор года используют материал контролов главной из `--design-glass-*`
и стоят в соседних колонках даже на 320 px. При увеличении текста до 200% на
узком экране подпись кнопки скрывается, доступное имя и tooltip сохраняются.
Для повышенного контраста и reduced transparency есть непрозрачный вариант.
Ссылка открывает
`/history?kind=constructors` с выбранным типом «Команды».

Единственный `YearSelect` ограничен 1958–текущим годом. Значение читается из URL,
смена сохраняет прочие параметры. Незавершённый ответ старого запроса не заменяет
новый сезон. Данные получает прежний `/api/constructors`; загрузка, пустой список,
ошибка и повтор представлены отдельно. Лишние вспомогательные запросы и скрытые
дубли мобильного/десктопного интерфейса удалены.

Изображения используют сезонные API и уже проверенный `spotlightTeamMedia` для
2026 года. Болид сохраняет пропорции и мягко растворяется по краям. Логотипы показаны без плиток и подложек, в квадратной области с сохранением
исходных пропорций. Для официальных эмблем 2026 года в компоненте сохранены
измеренные границы непрозрачного контура, поэтому масштаб и центр определяются
силуэтом, а не прозрачными полями квадратного файла. Видимый размер ограничен
34×30 px, круглые эмблемы — 28×28 px (значения выражены в rem для увеличения
текста). Исходные файлы не изменены; резервные API-изображения и другие сезоны
используют обычный contain. Номера мест центрированы в отдельной колонке.
В светлой теме применяется invert(1), в тёмной — исходные
цвета: внутренние детали эмблем сохраняются. Ошибка изображения не скрывает
название. Подсветка лидера непрерывная по всей области за болидом, затухают
только внешние края; подсветка строк зачёта остаётся прежней.
Сохранены общие панель темы/уведомлений/аккаунта, sidebar и мобильный dock.
Старые правила зачёта в глобальных CSS удалены; пустой standings-results.css и
его импорт больше не нужны. Остальные незавершённые изменения проекта сохранены.

Применены turbotears-page-design, frontend-design, web-design-guidelines,
apple-design (HIG Layout, Accessibility, Lists and tables) и Impeccable.
Сетка и размеры — решения реализации для React/web. Контраст вторичного текста
усилен той же смесью токенов, что у пилотов: 75% muted / 25% ink. При наиболее
сильной подсветке Ferrari 20% консервативная оценка — 4,82:1 в светлой и 9,07:1
в тёмной теме. Явный фокус 3 px, цели от 44 px, reduced motion и forced colors.

Предпросмотр: `npm run dev` из front, затем
`/tests/home-design-preview.html?page=constructors&auth=member`.
`auth=guest`, `theme=light|dark`, `scale=2`, `year=2025`; состояния
`state=constructors-loading|constructors-empty|constructors-error`.
Ошибка в fixture однократная, повтор успешен. Все спортивные значения демо
вымышлены; production не содержит моков. Сохранённый ручной выбор темы важнее URL.

Проверены обе темы, ширины 320, 390, 699, 899, 900, 1024, 1440, 1920 px
(промежуточные 699 и 1024 отдельно в светлой теме); текст 200% в обеих темах
на 320, 390, 900 и 1440 px. Нет горизонтального переполнения и обрезки строк.
Просмотрены загрузка, пустое состояние и ошибка с успешным повтором, гость и
участник, выбор сезона, переход к команде, видимый клавиатурный фокус 3 px,
прокрутка до последней строки выше dock. Реальный production API, отдельные
браузеры и полный аудит скринридером в этот проход не включены.

`npx tsc -b`, `npm run lint`, `npm run build:front`, `npm test` (206 тестов)
и `git diff --check` прошли. Сборка сохраняет существующее предупреждение о
крупном чанке игры. Один scoped Impeccable layout/type scan дал только
`overused-font` для сохранённого брендового Space Grotesk. Снимки обеих тем:
`.impeccable/review/constructors/`.


## Шкалы очков команд

На широком экране середину строк занимает «Соотношение очков»: длина шкалы
равна доле сезонных очков команды от очков первого участника зачёта. Шкала
использует уже загруженные данные `/api/constructors`, без дополнительного API.
Справа остаются отдельные точное отставание и очки. Нулевая разница — `0`,
отсутствующие значения — прочерк. Если у лидера ноль очков, заполнение не
вычисляется; ноль очков команды при ненулевом лидере даёт нулевую шкалу.
Декоративная шкала скрыта от AT, числовые очки/отставание доступны текстом.

При контейнере меньше 54rem шкалы и их заголовок скрываются, остаётся прежняя
адаптивная компоновка. Мобильные строки сохраняют 72px при обычном тексте.
Цвет заполнения, как в зачёте пилотов: 55% командного цвета и 45% design-ink.
Измеренный контраст с дорожкой по всем 11 командам: от 3,25:1 в светлой теме
и 4,15:1 в тёмной. Для forced colors и повышенного контраста есть замена цвета.

Изолированные preview-состояния: constructors-zero, constructors-missing,
constructors-tied. Проверены значения шкал, отсутствие деления на ноль,
прочерк при null и равенство очков без «−0». Это вымышленные демонстрационные
данные; проверка production API не входила в визуальную задачу.

Проверки этого прохода: обе темы на 390 и 1440 px; ширины 320, 899, 900,
1199/1200/1201 и 1920 px; текст 200% на 320, 390, 900 и 1440 px.
Нет горизонтального переполнения, граница появления шкал соответствует ширине
контейнера 54rem. Повтор после ошибки загрузил все 11 команд. Проверены
клавиатурный фокус и ссылки с выбранным сезоном. TypeScript, ESLint, production
build и 207 frontend-тестов прошли. Scoped Impeccable scan дал только
предупреждение о сохранённом Space Grotesk. Снимки: points-bars-light.png и
points-bars-dark.png в `.impeccable/review/constructors/`.
