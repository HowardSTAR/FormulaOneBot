# Оформление админ-панели

`/admin` использует общий `glass-home`/`HomeToolbar`, существующие права доступа и все прежние административные API. Страница предназначена для выполнения задач: спокойные поверхности, одна рабочая область и локальная навигация. Общий мобильный и настольный каркас остаётся независимым от выбора административного раздела; по запросу пользователя правовой футер в админ-панели не отображается.

На широком экране разделы представлены нативными ссылками, на компактном — существующим `SelectField`. Выбор хранится в `section`. Блокировка перехода во время пересчёта сохранена. Список пользователей на телефоне использует тот же DOM таблицы с подписями полей и отдельным выбором сортировки; скрытые кнопки заголовка исключены из последовательности Tab. Диалог email использует нативный `dialog` с удержанием фокуса и Escape. Ошибка сохранения остаётся внутри диалога, сохраняет адрес и возвращает фокус к полю; после успеха обновляется только список пользователей. Ошибка обновления списка отделена от успешного сохранения email.

Цвета взяты из `--design-*`, шрифт заголовка — принятый Space Grotesk. Основные пары: светлая тема `#202126` / `#fff`, вторичный `#64666e` / `#fff`, акцент `#b92b25` / `#faeeec`; тёмная тема `#f2f2f4` / `#202125`, вторичный `#b0b1ba` / `#202125`, акцент `#ff9b92` / `#382522`. Без нового иллюстративного баннера и анимации.

## Локальный предпросмотр

`/tests/home-design-preview.html?page=admin&auth=member`

Параметры: `section=users|audit|overview|notifications|recovery|recap-news|games|tools|control`, `state=admin-error|admin-empty|admin-denied|admin-loading|admin-save-error`, `role=admin`, `scale=2`. Данные вымышлены, административные запросы перехватываются только тестовым entrypoint; изменения не отправляются на сервер. Email тестового пользователя можно сохранить в памяти до перезагрузки; `admin-save-error` сначала возвращает ошибку, затем позволяет повторить сохранение.

## Проверки

Проверены светлая и тёмная темы, 320/390/1100/1101/1440/1920 px, текст 200%, переключение разделов, раскрытие действий, диалог email и Escape, поиск без совпадений, фильтр журнала, ошибка и повтор загрузки. TypeScript, точечный ESLint, `build:front` и все 209 frontend-тестов проходят. Аналитика поддерживает масштабирование текста и одну колонку на узком экране; активный раздел доступен вспомогательным технологиям. Impeccable detect сообщает только о Space Grotesk, который закреплён дизайном проекта.

В проверке равной высоты карточек исключено устаревшее ожидание для `.community-grid`: в сообществе независимые колонки намеренно используют `align-items: start`. Реальные рассылки, удаление данных и изменение ролей в рамках визуальной проверки не выполнялись.
