# Сравнение TurboTears

`/compare` продолжает оформление главной и зачётов: семантические `--design-*`
цвета обеих тем, общая панель аккаунта, сезонные `DriverPortrait` и мягкая
командная подсветка. Основная задача — выбрать участников и сопоставить сезон.
Порядок единого адаптивного DOM: заголовок и сезон, участники, краткая сводка,
таблица, график и раскрываемые точные значения. На широком экране портреты
расположены рядом; на телефоне участники идут вертикально. У таблиц собственная
горизонтальная прокрутка с клавиатурным фокусом.

Сохранены API пилотов, команд и автоматического сравнения, выбор всех участников,
поиск, удаление, исторические сезоны и доступ гостя. Серверная логика и права
не менялись. Повторное нажатие на активную вкладку или сезон больше не прерывает
текущий запрос. Пакетный выбор использует нативный dialog в верхнем слое: окно на десктопе
и панель снизу на телефоне. Фотографии пилотов и логотипы команд стоят рядом
с именами. Можно отметить нескольких участников, выбрать всех либо найденных,
сбросить отметки и добавить весь набор одним действием. Поиск сохраняет отметки,
закрытие без добавления их отменяет. Escape возвращает фокус на кнопку добавления;
при добавлении всех фокус переходит на раздел участников. Заголовок и нижняя
панель действий остаются видимыми при прокрутке списка. Цели управления от 44px, фокус 3px; есть варианты reduced
motion, reduced transparency, повышенного контраста и forced colors.

График использует токены темы, штрихи разных линий и текстовую легенду. Цвета
линий корректируются до контраста минимум 3,1:1 относительно фона каждой темы;
эта гарантия проверяется отдельным тестом палитры. Space Grotesk сохранён для
чисел. Предупреждение scoped Impeccable layout/type scan относится только
к этому принятому шрифту. Прежние отдельные стили сравнения удалены из глобальных
CSS. Существующие изменения других страниц сохранены.

Предпросмотр: `npm run dev` из `front`, затем
`/tests/home-design-preview.html?page=compare&auth=member`.
Параметры: `auth=guest|member`, `theme=light|dark`, `scale=2`,
`state=compare-error|compare-empty|compare-loading`. Ошибка однократная,
повтор успешен. Фикстуры полностью отделены от production, значения вымышлены
и явно обозначены. Сохранённая ручная тема имеет приоритет над параметром URL.

В Chromium/IAB просмотрены светлая и тёмная темы на телефоне 390px и десктопе
1440px, дополнительно проверены 320px, границы 699/700 и 899/900px, 1920px,
текст 200% (320–1440px). Проверены поиск, добавление, удаление, все 22 пилота,
переключение команд, выбор 2025/2026, загрузка, пустой результат, ошибка и повтор,
Escape и видимый фокус. Снимки: `.impeccable/review/compare/`.

TypeScript, ESLint, сборка frontend и 207 тестов прошли. Сборка сохраняет
предупреждение о большом чанке игры. Реальный backend, отдельные Safari/Firefox
и полная проверка скринридером не выполнялись. Полное соответствие WCAG этим
проходом не заявляется.

## Пакетный выбор и кнопки

Переключатель пилотов/команд использует стеклянную линзу и иконки сайта, кнопка
добавления — общий материал контролов. Карточки выбора компактные (от 80px),
с круглыми стеклянными отметками вместо стандартных квадратов. Нативные
checkbox сохраняют семантику и клавиатурное управление; явный фокус строки
появляется при клавиатурном вводе. На десктопе ширина окна до 720px, список
в две колонки; на телефоне одна колонка. Логотипы появились и у уже выбранных
команд. Источники и измеренные alpha bounds общие с зачётом команд; исторические
сезоны используют прежний API и текстовый fallback при отсутствии изображения.

Дополнительно проверены пакетное добавление четырёх пилотов, выбор команд,
сохранение отметок при поиске, выбор найденных, сброс, отмена по Escape,
повторное открытие без прежнего черновика, возврат фокуса, загрузка логотипов,
обе темы и мобильная ширина 320px. Проверки относятся к изолированному демо.
