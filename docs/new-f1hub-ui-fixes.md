# Локальная проверка исправлений new.f1hub.ru

Изменения подготовлены локально. Демо импортируется только Vite-страницами в
`front/tests/`; production entry point не использует тестовые ответы.

## Что исправлено

- Общий `DriverPortrait` предпочитает оригинал выбранного сезона перед headshot.
  Поясное кадрирование используется на главной, в карточках пилота и команды,
  выборе пилотов, зачёте, истории и избранном. Готовый короткий портрет повторно
  не увеличивается. Смена участника сбрасывает цепочку резервных изображений.
- Логотип и болид на главной имеют отдельные области, включая desktop overview.
  Прозрачные поля нормализованного логотипа не создают горизонтальную прокрутку.
- Календарь и уик-энд рисуют контур при появлении; reduced motion оставляет готовую
  схему. Невалидный SVG показывает сообщение, а не текст XML/HTML-сущностей.
  У фонового выделения карты уик-энда убрана заливка; фокус и статистика доступны.
- Флаг национальности снова заполняет шапку с прежней прозрачностью и затуханием
  четырёх краёв. SVG-сцена сохраняет все полосы широкого фона. Сцены гонки
  продолжают использовать прежний режим `RaceFlagBackdrop`.
- Условия чемпионства получили золотистую сцену с кубком, сезонным портретом
  претендента и логотипом команды: две группы на широком экране, одна на узком.
  Единая ветка рендера сохраняет просмотр, редактирование и выбор претендента.
- Разделы прогнозов переключаются компактной плашкой. Таблица получила поиск,
  сортировку, переход с фокусом к своей строке, итоги рядом с именем и раскрытие
  вторичной статистики. Сохраняются закреплённые колонки, заголовки и личный разбор.
- «Мой сезон» объединяет последний результат с сезонной сводкой; все этапы,
  точность, достижения и отправка результата сохранены.
- В сообществе удалена дублирующая фоновая трасса. В профиле декор избранного
  равномерно распределяет все выбранные изображения по площади блока,
  а кнопка профиля использует сохранённый аватар. Неудачное сохранение не меняет
  аватар; успешное сразу обновляет шапку.

## Запуск

Из `front/`: `npm run dev -- --host 127.0.0.1`.
Открыть `/tests/production-layout-preview.html` на порту, указанном Vite.
В текущей проверке Vite использует `http://127.0.0.1:5174`.
На странице собраны ссылки на обе темы, плотные данные и гостевой режим.
Выбранная вручную тема сохраняется и имеет приоритет над темой ссылки.

## Проверки

- TypeScript, ESLint, `npm run build:front`, 209 frontend/navigation tests.
- `scripts/check-predictions-design.cjs`: обе темы, 320–1920 px, окна приёма,
  ошибки/повтор, сохранение, спринт, выбор без повторов, личный разбор, ссылки,
  перетаскивание переключателя, клавиатура, 200% текста и повышенный контраст.
- `scripts/check-production-layout.cjs`: обе темы, 320/390/900/1200/1440/2560 px;
  семь основных экранов, главная, все изображения избранного, плотная таблица,
  анимация/ошибка схемы, открытие статистики, поиск/фокус/личный разбор и реальное
  сохранение аватара на изолированном API с ошибкой, повтором и перезагрузкой.
  `UI_BASE_URL` задаёт порт; `NODE_PATH` должен указывать на доступный Playwright.
- Дополнительно проверены 200% текста на пяти изменённых страницах при
  320/390/900/1440 px в обеих темах; длинные имена таблицы переходят к общей
  горизонтальной прокрутке вместо сжатия закреплённых колонок.
- Сохранённые снимки проверены визуально. Scoped Impeccable layout/type scan дал
  только предупреждения об уже принятом фирменном Space Grotesk;
  шрифт сохранён по дизайн-контракту проекта.

Проверки используют вымышленные ответы и не подтверждают состояние production API.
