# Сообщество

`/community` использует общую оболочку `HomeToolbar` / `glass-home`,
семантические `--design-*` токены обеих тем и Space Grotesk в заголовках.
В меню — прямая ссылка «Сообщество» без группы «С друзьями». Голосование
остаётся отдельной ссылкой с прежними правами. Название согласовано с вкладкой,
знакомством с сайтом и пояснением к публичным карточкам.

## Композиция

Без контекстного напоминания десктопный заголовок стоит в одной верхней полосе
с инструментами; при наличии напоминания его строка сохраняется. Основное
действие — «Проехать три круга» на трассе недели. Ниже — зачёт и лиги.
Достижения стоят под зачётом независимо от высоты лиг. На телефоне порядок:
трасса, зачёт, лиги, достижения. Юридический footer сохранён.

## Карта и демонстрация

`/api/engagement/weekly` определяет трассу и период. Окружение, геометрия,
движение болида и ссылка заезда используют один `track_id`. В конце периода
страница перечитывает API и переключает весь блок на новую трассу.
Неизвестный ID получает явное состояние; ошибка картинки оставляет контур
той же трассы. Архив сохраняет выбранную прошлую неделю и всех победителей
при одинаковом времени.

Геометрия берётся из `app/race_tracks.json`. Четыре WebP-фона в
`front/src/assets/community/` отрисованы `race-game/src/trackRenderer.ts`:
повторяемый экспорт — `scripts/render-community-tracks.cjs`, Vite-fixture —
`front/tests/community-track-render.html`. В production странице Phaser не нужен.

Все четыре края карты мягко растворяются в поверхность секции. Подпись,
пауза и клавиатурный фокус находятся вне маски. Болид непрерывно проходит
круги; пауза и продолжение сохраняют позицию. Вне видимости и в скрытой вкладке
демонстрация не продвигается. Reduced motion получает статичную карту;
повышенный контраст отключает декоративное растворение. Демо не создаёт
игровой результат или очки.

## Личные данные

Место, время и отставание из `/api/engagement/weekly/me` видны только при
совпадении трассы и недели. Сначала показывается пятёрка зачёта, остальные
полученные строки раскрываются кнопкой. API ограничен 50 результатами;
это число не выдаётся за всех участников. Ничьи сохраняют одинаковое место.
Ссылки `/api/predictions/leagues` сохраняют сезон выбранной лиги. Шлемы —
декоративное превью компании, не вымышленные участники.

«Друзья и достижения» показывает серверные награды и условия их получения.
Пустой блок не состоит из нулей. Статистика приглашений раскрывается при
наличии активности; публичные карточки можно открыть или отозвать. Сохранены
независимые ошибки и повтор, защита от повторного отзыва, прежние права
website/Telegram/подписки. Стили `/share/:token` изолированы в `share.css`.

## Проверки

- `scripts/check-community-weekly-ui.cjs`: обе темы, 320/390/899/900/1440/1920/
  2560 px, текст 200%, длинные имена, пустые результаты, ничьи, архив,
  раскрытие по Enter, ссылки гостя/аккаунта, ошибки и повтор, отзыв карточек,
  отсутствие overflow, непрерывный круг, пауза/продолжение и reduced motion.
- `scripts/check-community-preview.cjs`: именно общее демо, четыре картинки
  с реальным декодированием, видимость карты, движение и ссылки, недоступное
  изображение, неизвестный ID, смена недели с часами браузера.
- Тесты навигации/символов, TypeScript, ESLint изменённых компонентов,
  frontend build. Impeccable отметил только принятый шрифт Space Grotesk.

Адрес общего демо: `front/tests/home-design-preview.html?page=community`,
параметры `theme`, `auth`, `scale=2`, `track=<ID из JSON>`. Название и ID
берутся из общего каталога: прежний `emerald-loop` не соответствовал
`emerald-loop-v2` и скрывал карту. Регрессия проверяется через собственный
fetch-fixture демо без его внешней подмены. Все UI-сценарии используют
демонстрационные ответы и не подтверждают работу production backend.
