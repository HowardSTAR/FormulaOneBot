# Новые инструменты админки

Доступ: `/admin`, только admin/superadmin. Публикация постов исключена.

## Аналитика

Дополнительный блок «Аудитория и уведомления» имеет собственный период 7/30/90 дней
и CSV без персональных данных: регистрации, уникальные и вернувшиеся браузеры,
доступная аудитория уведомлений, push, число прочитанных уведомлений.
Аккаунты, каналы и избранные пилоты — текущий срез, а не историческая фотография.
Возвращаемость означает визит в разные дни UTC внутри выбранного периода; это не
когортное удержание. Cookie не позволяет определить уникального человека между устройствами.

## Точечные уведомления

Вкладка «Уведомления» пишет в историю сайта; push включается отдельно и требует
VAPID и работающего существующего обработчика `poll_web_notifications`.
Telegram-сообщения и email эта форма не отправляет.

1. Выберите аккаунты поиском/внутренними ID или сегмент: все, администраторы,
   активные/неактивные за 30 дней. Дополнительный фильтр — избранный пилот.
2. Введите заголовок, обычный текст и внутреннюю ссылку сайта.
3. Нажмите «Проверить аудиторию». Никаких сообщений на этом шаге не создаётся.
4. Проверьте количество и первые 20 получателей. Для реальной отправки введите
   `ОТПРАВИТЬ` и нажмите кнопку отправки.

Получатели — только аккаунты, ранее открывавшие уведомления сайта. Гости и архивные
аккаунты исключены. Неактивные включают аккаунты без записанной активности за 30 дней.
Максимум 1000 получателей; при выборе ID — до 500 значений.
Список фиксируется на час. Смена формы требует нового предпросмотра. При отправке
проверяются актуальные членство, архивный статус и роль (для административного сегмента).
Предпросмотр может отправить только его автор. Транзакция и уникальные ключи защищают
от повторного запроса/двойного клика; новый предпросмотр считается другой отправкой.
Если ответ потерялся, сначала обновите историю, не создавайте новую отправку.

История показывает последние 50 проверок/отправок и прочтения; «Прочитать все» также
считается прочтением. Постановка push в очередь не равна доставке. Текущая общая очередь
не различает все причины закрытия задания; намеренно не показывается ложный показатель
«доставлено». Существующий обработчик пропускает старые push при перезапуске; история
сайта сохраняется. Локальный API сам не запускает push-обработчик.

## Инструменты

Вкладка «Инструменты» содержит описание существующих разделов и ссылки на закрытую
аналитику предсказаний и личные уведомления. Служебные команды Telegram описаны,
но не запускаются автоматически.

Миграции таблиц выполняются обычным `db.init_tables()` при старте API/бота.
Все API защищены существующей проверкой роли и CSRF для cookie-сессий.
Тесты: `python -m pytest tests/test_admin_tools.py -q` — только временная SQLite,
никаких реальных сетевых отправок.
