# Иконки навигации

Исходные PNG находятся в `front/src/assets/navigation`; компонент `IndexIcon`
использует этот каталог на компьютере и телефоне. Изображения уже содержат
тёмную основу, красную рамку, объём и блики, поэтому дополнительная рамка в CSS
не нужна.

Новые иконки `social.png`, `games.png`, `help.png` подготовлены встроенным
imagegen по образцам `account.png`, `home.png` и прежнего `games.png`.
Размер файлов — 128 × 128, внешний фон прозрачен; в меню они отображаются
в размере 32 × 32, внутри подменю — 28 × 28.

Промпты: сохранить чёрную скруглённую плитку, тонкую красную объёмную рамку,
красную эмаль и металлические блики исходного набора. Для «С друзьями» — две
фигуры людей; для «Игр» — красный геймпад с серебристыми кнопками; для «Помощи» —
объёмный знак вопроса. Без надписей, зелёного цвета и плоских контурных символов.

`scripts/pack-navigation-icons.ps1` обновляет 29 иконок в `app-assets.zip`,
проверяет их хеши, сохраняет остальные файлы архива и синхронизирует локальный
распакованный каталог `app/assets/navigation`.
