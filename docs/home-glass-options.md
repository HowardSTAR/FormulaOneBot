# Три варианта главной с Liquid Glass

Исследование композиций от 23 октября 2026 года в ветке `feature/new_design`.
React Web / Telegram Mini App, телефон и десктоп. Задача главной — сразу показать
ближайшую сессию, её время и переход к прогнозу, затем расписание и зачёт.

## Как посмотреть

Из `front` запустить `npm run dev`, открыть `/tests/home-glass-options.html`.
Галерея одновременно показывает окна 1200 × 1000 и 390 × 844 CSS px. Десктоп
уменьшён только для сравнения: ссылка «Открыть отдельно» показывает адаптивную
страницу в реальном размере окна. Макеты прокручиваются независимо.

Доступны светлая/тёмная тема, отключение прозрачности и увеличение текста 200%.
Выбор темы использует существующий переключатель и сохраняется. Данные
вымышлены и зафиксированы на 23.10.2026, 15:00 МСК; обратный отсчёт статичен.
Входящих и исходящих запросов к API из макетов нет. Ссылки ведут в существующие
разделы; уик-энд открывает прежний изолированный предпросмотр.

## Композиции

- **Фокус на этапе** (`?variant=focus`). Спокойная главная: карточка этапа и
  личное действие слева, расписание справа, зачёты ниже. На телефоне — компактный
  красный акцент на ближайшей сессии. Узнаваемый элемент — схема реальной трассы
  и узкая красная полоса карточки на десктопе.
- **Панорама трассы** (`?variant=panorama`). Крупная схема Circuit of the Americas
  и название гонки на графитовой поверхности; плавающая верхняя навигация на
  десктопе. На телефоне схема компактно дополняет карточку. Выразительность
  сосредоточена на одном элементе — трассе, а остальные блоки остаются спокойными.
- **Пит-уолл** (`?variant=pitwall`). Плотная рабочая композиция: этап, прогноз и
  расписание слева, оба зачёта справа. На телефоне — единая лента без лишнего
  контейнера вокруг прогноза. Узнаваемость создают расписание с разными символами
  сессий и табличная типографика очков.

Схемы компактной и широкой компоновок:

```text
Телефон (все):       Панель → этап → прогноз → расписание → зачёты
                    Плавающая навигация у нижнего края

Фокус, десктоп:      Боковая навигация │ этап       │ расписание
                                     │ прогноз    │
                                     │ пилоты     │ команды

Панорама, десктоп:   Плавающая верхняя навигация
                    Этап и крупная схема трассы
                    Прогноз + зачёты             │ расписание

Пит-уолл, десктоп:   Боковая навигация │ этап       │ пилоты
                                     │ прогноз    │ команды
                                     │ расписание │
```

Это предложения композиций для TurboTears, а не заданные Apple макеты.
Полноэкранная иллюстрация гоночного автомобиля, дополнительные декоративные
кнопки и автоматически меняющиеся слайды не добавлялись: они не помогают
определить время старта. Шрифт системный, цифры времени и очков — табличные.
Мобильный заголовок 30–34 px, основной текст расписания 17 px, метаданные 11–12 px,
подписи навигации 11 px. Размеры заданы в rem, автоматического движения нет.

## Как применён скилл

Прочитаны установленный `apple-design/SKILL.md`, `hig-lookup.md`,
`cross-platform.md`, accessibility, layout, typography, color,
designing-for-ios, designing-for-macos, materials, liquid-glass, tab-bars и sidebars.

- `materials.md › Liquid Glass`: стекло относится к функциональному слою.
  Оно используется в панели управления, боковой/нижней навигации и кнопке
  «Наверх». Содержимое остаётся непрозрачным.
- `liquid-glass.md › Cross-platform translation`: CSS передаёт размытие,
  полупрозрачность и светлую кромку. Это приближение к материалу Apple,
  без нативной рефракции и автоматического анализа яркости под контролами.
- `layout.md › Visual hierarchy`: ближайшая сессия находится первой,
  второстепенные разделы доступны через нативное раскрытие.
- `tab-bars.md › Best practices`: нижние ссылки подписаны и открывают разделы;
  действие «Сделать прогноз» находится в содержимом, отдельно от навигации.
- `sidebars.md › Best practices`: навигация на десктопе сгруппирована,
  не имеет глубокой иерархии и может прокручиваться при недостаточной высоте.
- `typography.md › Ensuring legibility` и `accessibility.md › Vision`:
  системный шрифт, контрастные подписи, увеличение текста и переносы строк.

Размытие 28 px, заливка компактных панелей 74%, скругления и размеры сеток —
параметры этой веб-реализации, не спецификация Apple. Боковая панель использует
более плотную заливку общих токенов. Видимый ручной переключатель темы сохранён
по прямому требованию пользователя.

## Палитра и проверка

Используются общие `--design-*` токены, новые цвета ограничены графитовой
поверхностью панорамы и схемой трассы. Вычисленный контраст sRGB:

- Светлая поверхность `#ffffff`: основной `#202126` — 16,07:1,
  вторичный `#64666e` — 5,73:1, акцент `#b92b25` — 6,11:1.
- Тёмная поверхность `#202125`: основной `#f2f2f4` — 14,39:1,
  вторичный `#b0b1ba` — 7,54:1, акцент `#ff9b92` — 7,93:1.
- Панорама `#27292e`: вторичный `#d2d3d9` — 9,74:1.
- Белый текст на красной карточке `#b92b25` — 6,11:1.

На компактном стекле текст и символы монохромные; выбранный раздел получает
непрозрачную подложку. При отключении прозрачности, `prefers-reduced-transparency`
или `prefers-contrast` панели становятся сплошными. Есть отдельные правила для
forced colors и reduced motion. Контраст полупрозрачных поверхностей зависит
от содержимого под ними и требует повторной проверки при интеграции.

В браузере проверены обе темы, композиции 1200/390 px, все три варианта при
ширине 320 px и тексте 200%: горизонтального переполнения документа нет.
Проверены переключение вариантов, непрозрачные панели, раскрытие с Enter,
появление кнопки «Наверх» и перенос фокуса в основной контент после нажатия.
ESLint и отдельная проверка TypeScript для TSX-предпросмотра прошли.

Цель — [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/): контраст, клавиатура,
видимый фокус, переносы, понятные имена и доступные цели нажатия. В макетах
управление имеет области минимум 44 × 44 CSS px. Полное соответствие не
подтверждено: это варианты дизайна, без проверки реальным скринридером и всех
пользовательских сценариев. Материал описан в
[Apple HIG — Materials](https://developer.apple.com/design/human-interface-guidelines/materials).
